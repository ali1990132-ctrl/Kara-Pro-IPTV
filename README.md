# كارة برو — مشغّل IPTV (Android / Kotlin)

مشغّل IPTV مبني من الصفر، يدعم **Xtream Codes** و **روابط M3U/M3U8**،
بواجهة عربية (RTL) وترتيب أيقونات على نمط تطبيقات الماكس المعروفة:
شريط علوي بمعلومات الاشتراك + شبكة أيقونات (بث مباشر / أفلام / مسلسلات / إعدادات).

> ملاحظة: كل الأيقونات والتصاميم أصلية داخل المشروع، غير منسوخة من أي تطبيق آخر.

---

## المتطلبات
- **Android Studio** (Hedgehog 2023.1.1 أو أحدث)
- **JDK 17** (يأتي مدمج مع Android Studio)
- جهاز أو محاكي بنظام Android 5.0 (API 21) أو أحدث

## طريقة الفتح والبناء
1. افتح Android Studio ثم: **File → Open** واختر مجلد `KaraProIPTV`.
2. انتظر حتى يكمل **Gradle Sync** (سيحمّل المكتبات تلقائياً — يحتاج إنترنت أول مرة).
3. وصّل جهازك (أو شغّل محاكي) واضغط **Run ▶**.
4. لبناء ملف APK للتوزيع: **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
   يطلع الملف في `app/build/outputs/apk/`.

## طريقة الاستخدام داخل التطبيق
- **تبويب Xtream Codes:** أدخل عنوان السيرفر (`http://host:port`) + اسم المستخدم + كلمة المرور.
- **تبويب رابط M3U:** أدخل رابط قائمة التشغيل مباشرة.
- خيار "تذكّرني" يحفظ بيانات الدخول ويدخل تلقائياً بالمرة الجاية.

## بنية المشروع
```
app/src/main/java/com/karastore/iptv/
├── data/
│   ├── Session.kt         بيانات الجلسة + حفظها محلياً
│   ├── XtreamApi.kt        الاتصال بـ Xtream Codes API
│   ├── M3uRepository.kt    تحميل وتحليل قوائم M3U
│   ├── Repo.kt             مستودع موحّد يخفي الفرق بين النوعين
│   └── model/Models.kt     نماذج البيانات
└── ui/
    ├── login/              شاشة تسجيل الدخول
    ├── home/               الشاشة الرئيسية (ترتيب الماكس)
    ├── list/               قوائم التصنيفات والقنوات/الأفلام/المسلسلات
    ├── player/             مشغّل ExoPlayer (Media3)
    └── adapters/           محوّلات القوائم
```

## التخصيص السريع
- **اسم التطبيق:** `res/values/strings.xml` → `app_name`
- **الألوان والهوية:** `res/values/colors.xml` (`accent` هو اللون الأساسي)
- **ألوان الأيقونات بالرئيسية:** ملفات `res/drawable/tile_*.xml`
- **أيقونة التطبيق:** `res/drawable/ic_launcher.xml`
- **اسم الحزمة (applicationId):** `app/build.gradle.kts`

## ملاحظات تقنية
- التشغيل عبر **AndroidX Media3 (ExoPlayer)** — يدعم `.ts` و `.m3u8` و `.mp4`.
- `usesCleartextTraffic=true` مفعّل لأن أغلب سيرفرات IPTV تستخدم `http`.
- المسلسلات: الضغط على مسلسل يفتح قائمة حلقاته (عبر `get_series_info`).
