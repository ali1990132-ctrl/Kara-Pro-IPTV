# A&S Shorts 🎬

تطبيق مسلسلات قصيرة (أنمي + كوري) — المطوّر: علي جمال العامري

## مكان المشروع
فرع **as-shorts** بمستودع Kara-Pro-IPTV. كل رفع على هذا الفرع يبني APK تلقائياً بـ Actions.
رابط التحميل الثابت:
`https://github.com/ali1990132-ctrl/Kara-Pro-IPTV/releases/download/as-shorts-latest/A-S-Shorts.apk`


## إضافة مسلسلات وحلقات
كل المحتوى بملف واحد: `content/shorts.json`
- عدّله من GitHub مباشرة، أو استخدم **editor.html** (محرر بالعربي: تضيف مسلسل، بوستر، روابط الحلقات، وتنسخ الملف).
- التعديل يطلع بالتطبيق فوراً بدون إصدار جديد (زر ↻ بالرئيسية أو إعادة فتح التطبيق).
- تعديل ملف المحتوى ما يشغّل بناء APK جديد.

### شكل المسلسل
```json
{
  "id": "my-series-1",
  "title": "اسم المسلسل",
  "category": "korean",
  "poster": "https://.../poster.jpg",
  "year": 2026,
  "featured": true,
  "new": true,
  "tags": ["رومانسي", "دراما"],
  "description": "القصة...",
  "episodes": [
    { "title": "الحلقة 1", "url": "https://.../ep1.mp4" },
    { "title": "الحلقة 2", "url": "https://.../ep2.m3u8" }
  ]
}
```
- `category` لازم يطابق `id` من `categories` (`anime` أو `korean` أو أي قسم تضيفه).
- الروابط: mp4 أو m3u8 مباشرة، أو روابط يوتيوب.
- **أسهل طريقة:** بدل `episodes` حط `"youtubePlaylist": "PL..."` (رابط أو رقم قائمة تشغيل يوتيوب) والتطبيق يجيب كل الحلقات والصورة تلقائياً.
- استخدم قوائم من قنوات رسمية بس (سبيستون، الكابتن ماجد، KBS WORLD TV، PlayList Global...). بعض القنوات (مثل Muse Asia) مقفولة على دول آسيا وما تشتغل بالعراق.
- `featured` = يظهر بالواجهة الكبيرة، `new` = عليه شارة "جديد".

## التحديث داخل التطبيق
رقم إصدار التطبيق = رقم البناء بـ Actions (يظهر بالـ Release).
إذا نزّلت نسخة جديدة وتريد المستخدمين يحدّثون: حط رقمها بـ `app.latestVersion` بملف المحتوى.

## الميزات
- رئيسية: بانر متحرك، أكمل المشاهدة، جديد، أقسام، فلترة.
- مشغل عمودي بالسحب مثل تيك توك، تشغيل تلقائي للحلقة الجاية، يكمل من نفس الدقيقة.
- اكتشف: سحب بين المسلسلات.
- قائمتي (المفضلة + سجل المشاهدة)، بحث يفهم العربي (أ/ا، ة/ه)، سرعة تشغيل، مشاركة.
- يشتغل بدون نت بآخر محتوى محفوظ.

## التوقيع
مفتاح التوقيع `app/release.jks` ثابت حتى التحديثات تنزل فوق النسخة القديمة بدون حذف. لا تحذفه.
