# MT LIVE — مشغّل IPTV (Android / Kotlin)

نسخة MT LIVE: تسجيل دخول عن طريق **الهوست فقط** (Xtream Codes: رابط السيرفر + اسم المستخدم + كلمة المرور)، بدون M3U.

- شاشة افتتاحية بشعار MT LIVE
- بطاقة تسجيل دخول بالنص (Host / Username / Password)
- شريط علوي: الرئيسية | بث مباشر | أفلام | مسلسلات + مستطيل "الاشتراك ينتهي"
- قائمة أقسام مع العدد + شبكة بوسترات، وصفحة تفاصيل مع المواسم والحلقات
- مشغّل ExoPlayer مع تنقّل القنوات بالريموت

البناء تلقائي عبر GitHub Actions على فرع `mt-live`، والملف يطلع بإصدار `mt-live-latest` باسم `MT-LIVE.apk`.
